## 確認できる内容

- パンフレットと連動した3種類のファーストビュー
- 商品紹介と消費者向けアンケート
- 回答後のWhatsAppステッカー4枚セットの紹介
- ステッカー受け取り用メールアドレスの入力画面

## レビュー時のお願い

現在は確認用のプレビューです。試しに回答する場合は、実在する個人情報を入力せず、メール欄は `review@example.com` などのテスト用アドレスをご使用ください。

回答はサイト内のデータベースに保存されます。メール未入力でもアンケート回答は残ります。
メール登録完了後に4枚の透過PNGを表示します。画像を長押しして写真へ保存する操作をiPhone・Android別に案内し、その下にWhatsAppでステッカーにする画像付き手順を表示します。ZIPや自動ダウンロードは使用しません。Sticker.lyも不要です。スプレッドシートへの自動転記・メール自動送信は、まだ稼働していません。

配布画像は暗号化して保持し、メール登録後の期限付きHttpOnly Cookieをサーバーで検証して配信します。`STICKER_ASSET_KEY`はSitesのシークレットとして設定し、ソースには含めません。FVと登録前の画像にはSAMPLE透かしが入っています。受け取った後の画像の再配布やスクリーンショットは防止できません。
